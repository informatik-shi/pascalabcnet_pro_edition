# Тетрадки PascalABC.NET и SPython

`PascalABCNotebook` — отдельное приложение из portable-сборки. Оно запускает
локальный сервер на `127.0.0.1`, открывает браузер и предлагает создать
тетрадку PascalABC.NET или SPython. Код и текстовый вывод остаются в ячейке;
графика появляется **сразу под ячейкой в браузере** в виде PNG, без необходимости
смотреть на отдельное графическое окно.

[Скачать готовый portable-архив для Windows x64](https://github.com/informatik-shi/pascalabcnet_pro_edition/releases/download/portable-2026-10-08.2/PascalABCNET-Portable-win-x64.zip).

## Использование готовой сборки

1. Распакуйте весь portable-архив в папку, доступную для записи.
2. Запустите `PascalABCNotebook.cmd` в корне распакованной папки. Приложение
   откроет браузер автоматически. Если браузер не запустился, откройте адрес,
   напечатанный в консоли.
3. Выберите **PascalABC.NET** или **SPython**, введите код и нажмите
   **Выполнить**. `Ctrl+Enter` выполняет текущую ячейку, `Shift+Enter` выполняет
   её и переводит курсор к следующей. Кнопка **Выполнить всё** запускает ячейки
   по порядку.
4. Тетрадки сохраняются автоматически в `Work\Notebooks` рядом с приложением.
   Остановите сервер с помощью `Ctrl+C` в его консоли.

На Windows требуется .NET Framework 4.7.2 или новее для классического
компилятора. .NET 10 Runtime входит в portable-архив. Сборка/установка SDK на
компьютере пользователя не требуется.

В каждой ячейке доступны обычные конструкции выбранного языка. При выполнении
компилируются текущая и предыдущие ячейки в порядке сверху вниз. Поэтому
определения из верхних ячеек доступны ниже, а выполнение нижней ячейки повторно
запускает код выше неё. Ячейки Pascal могут содержать `uses`, объявления и
операторы; целую программу с `end.` можно выполнить отдельной ячейкой.
Состояние процесса между разными запусками ячеек не сохраняется.

## Графика внутри страницы

Выберите **Графический пример…** в тетрадке PascalABC.NET или введите код:

```pascal
uses GraphABC;
SetWindowSize(480, 300);
Brush.Color := clSkyBlue;
FillCircle(240, 150, 90);
```

После выполнения под кодом появится изображение. Проверены следующие модули и
зависящие от них библиотеки:

| Холст | Модули | Способ получения изображения |
| --- | --- | --- |
| GraphABC | `GraphABC`, `ABCObjects`, `ABCButtons`, `ABCSprites`, `ABCHouse`, `TurtleABC`, `Drawman` | `GraphABC.SaveWindow` |
| GraphWPF | `GraphWPF`, `PlotWPF`, `WPFObjects`, `TurtleWPF`, `Turtle` | `GraphWPF.GraphWindow.Save` |
| Graph3D | `Graph3D` | `Graph3D.View3D.Save` |
| PlotML | `PlotML` | `PlotML.Plot.Save` |
| WPF | `WPF` | `WPF.SaveWindow` |

В автоматической проверке есть примеры `GraphABC`, `ABCObjects`, `TurtleABC`,
`GraphWPF`, `PlotWPF`, `Graph3D`, `PlotML`, `WPF` и графические ячейки SPython
с `GraphABC` и `GraphWPF`. Некоторые учебные модули выводят рисунок на один из
этих же холстов. Снимок делается в конце выполнения ячейки: анимации и
интерактивные события в PNG не продолжаются. Низкоуровневый `OpenGL` /
`OpenGLABC` сам создаёт графический контекст и не имеет общего метода
`SaveWindow`, поэтому для него нужен отдельный способ захвата кадра.

Тетрадка выполняет пользовательский код на компьютере, от имени текущего
пользователя. Открывайте чужие тетрадки только если доверяете их коду.

## Воспроизводимая сборка

Исходники приложения находятся в `PascalABCNotebook/`; браузерная часть — в
`PascalABCNotebook/wwwroot/`. Для сборки на Windows нужны .NET 10 SDK,
Windows Desktop Runtime 10 и инструменты сборки .NET Framework, перечисленные
в [`build-portable-spython.md`](build-portable-spython.md).

Из корня репозитория выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\build-portable.ps1
```

Сценарий собирает IDE, оба компилятора, приложение тетрадок, заново
компилирует стандартные Pascal-модули и создаёт
`Release\PascalABCNET-Portable-win-x64.zip`. В архиве находятся
`PascalABCNotebook.cmd`, каталог `notebook`, `bin` с классическим
компилятором и модулями, а также каталог `dotnet` с Runtime. Если SDK
установлен в нестандартном месте, добавьте `-DotnetRoot 'C:\путь\к\dotnet'`.
Для проверки новой упаковки уже собранных файлов можно использовать
`-SkipBuild`; после изменения исходников **всегда** выполняйте полную сборку.

Для проверки приложения до упаковки:

```powershell
& 'C:\Program Files\dotnet\dotnet.exe' build PascalABCNotebook\PascalABCNotebook.csproj -c Release
& 'C:\Program Files\dotnet\dotnet.exe' PascalABCNotebook\bin\Release\net10.0\PascalABCNotebook.dll --root . --port 50477 --no-browser
```

Во втором окне PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\test-notebook.ps1 -BaseUrl http://127.0.0.1:50477
```

Тест создаёт временные тетрадки, запускает ячейки обоих языков и проверяет,
что графические результаты действительно доступны через HTTP как PNG.
При проверке разработки можно добавить серверу
`--workdir .codex-build\notebook-testdata`, чтобы не записывать тестовые
тетрадки в рабочую папку пользователя. Для ручной проверки откройте адрес
сервера в браузере.

## Как работает inline-вывод

1. Сервер формирует временный исходный файл из ячеек тетрадки и компилирует
   его с помощью `bin\pabcnetcclear.exe`.
2. Для графических модулей сервер ставит `PABC_NOTEBOOK_INLINE=1`.
   Изменённые стандартные модули создают окно вне экрана; обычный запуск IDE
   без этой переменной сохраняет прежнее поведение.
3. В конец программы добавляется вызов сохранения активного графического
   холста в `image.png`. Сервер передаёт браузеру адрес готового PNG, и
   браузер показывает его под ячейкой.
   Для ячейки SPython с `import matplotlib.pyplot as plt` используется
   встроенный Python/Matplotlib и сохраняется активная фигура. Массивы NumPy
   и таблицы pandas можно передавать в Matplotlib в той же ячейке. Примеры и
   ограничения описаны в [руководстве по сборке](build-portable-spython.md#matplotlib-в-spython).
4. Временные исходники, исполняемые файлы и PNG хранятся в
   `Work\Notebooks\<ID>\runs\<ID>`. Текст тетрадки хранится отдельно как JSON
   в `Work\Notebooks`. Выполнение ограничено 45 секундами на компиляцию и
   60 секундами на запуск одной ячейки.

Сервер принимает запросы только с локального компьютера (`127.0.0.1`);
изменяющие запросы требуют токен текущей сессии. Для переноса тетрадок
скопируйте всю папку `Work\Notebooks`.
