# Сравнение редакторов Qt и Tcl/Tk

Решение после сравнения: основной редактор — Qt. Дальнейшая разработка ведётся на нём, с ночной темой по умолчанию и двуязычными ошибками исполнения. Tcl/Tk остаётся историческим экспериментом. Размеры ниже относятся к пакетам на момент сравнения.

20 октября 2026 года. Сравниваются два работающих Windows x64 прототипа ABC Native,
которые используют один C++ интерпретатор Pascal. Для компактного учебного редактора
Tcl/Tk подходит: текущий ZIP примерно втрое меньше. Qt выбран для
дальнейшего развития среды с большим количеством панелей и инструментов.

## Что одинаково

В обоих редакторах есть один документ, подсветка, открытие и сохранение файла,
проверка программы, запуск, остановка и строка консольного ввода. Запуск использует
несохранённый снимок текста в отдельном процессе. Открытие другого файла и закрытие
редактора предлагают сохранить изменения.

Проверка типов и выполнение полностью остаются на C++. Выбор Tcl/Tk для интерфейса
не делает Pascal динамически типизированным и не превращает его программы в Tcl.
В обеих оболочках ошибка типов выявляется до запуска. В первом ядре реализованы
`integer`, `int64`, `real/double`, `boolean`, `string`, условия и циклы `while`.

## Размер и состав поставки

| Свойство | Qt | Tcl/Tk |
| --- | --- | --- |
| ZIP текущего прототипа | Около 15,6 МБ | Около 4,9 МБ |
| После распаковки | Около 34,3 МБ | Около 11,8 МБ |
| Код интерфейса | C++ и Qt Widgets | Tcl и небольшой C++ launcher |
| Доставляемые библиотеки | Qt DLL и плагины | Tcl/Tk DLL, zlib и скрипты runtime |
| Установка библиотек у пользователя | Не требуется | Не требуется |
| Интерпретатор Pascal | Общий C++ код | Общий C++ код |

МБ здесь означает 1 000 000 байт. Это измерения конкретных Release-пакетов MSVC:
Qt 6.8.3 и Tcl/Tk 8.6.15. Они включают одинаковое ядро, примеры и библиотеки
Visual C++. Размеры не являются оценкой всех приложений на этих библиотеках.
Точные результаты очередной сборки записываются в `native/dist/comparison-sizes.json`.

Пакет Tcl/Tk меньше, но содержит много небольших скриптов и ресурсов. Он пока
не собран в единый Starpack. Наличие механизма
[Starkit и Starpack](https://www.tcl-lang.org/starkits/) само по себе не заменяет
проверку включённых C++ компонентов и нужного runtime для каждой платформы.

## Различия при дальнейшем развитии

**Tcl/Tk** позволяет менять поведение интерфейса скриптами. Его текстовый виджет
уже предоставляет выделение диапазонов тегами, отметки и undo/redo; это подходящая
основа для учебного редактора. См. [официальную документацию text](https://www.tcl-lang.org/man/tcl8.6.11/TkCmd/text.htm).
Придётся поддерживать и Tcl-код интерфейса, и C++ ядро. Ошибки Tcl-скриптов требуют
отдельного тестирования при выполнении.

**Qt** сохраняет интерфейс и ядро на одном языке C++. Текущий вариант использует
[QPlainTextEdit](https://doc.qt.io/qt-6.8/qplaintextedit.html) и штатные окна Qt.
Для расширенной среды это удобная отправная точка, но цена текущей поставки выше.
Развёртывание DLL и платформенных плагинов является самостоятельной частью сборки.

В обоих случаях автодополнение, поиск определений, просмотр типов и отладчик
должны обращаться к общему C++ анализатору. Выбор GUI не предоставляет эти
возможности автоматически. В прототипах они ещё не реализованы.

## Что проверено

- Ядро проходит 83 проверки: типы, области видимости, арифметика, Unicode,
  ввод/вывод, переполнение, лимиты и отказ на повреждённом байткоде.
- Каждый редактор запускает несохранённый пример, передаёт число 21 и проверяет
  результат 42.
- В распакованных пакетах проверяются запуск редактора, вычисление суммы от 1 до
  10 и отказ до первого вывода при ошибочном присваивании.
- Проверка пакетов очищает пути к Qt, Tcl/Tk и Python, использует временную папку
  с пробелами и кириллицей. Это проверка на текущем компьютере, а не испытание
  на чистой виртуальной машине.

Локальные испытания выполнены на Windows x64. Для ядра добавлен workflow сборки
и тестов на Windows, Ubuntu и macOS, но удалённый CI пока не запускался.
Пакеты редакторов для Linux/macOS ещё не собраны. Потребление памяти, работа с
большими файлами, масштабирование на разных мониторах и доступность не измерялись.
Время теста запуска не используется как оценка скорости редактора.

## Как попробовать

После сборки в `native/dist/` находятся `ABC-Native-Qt-win-x64.zip` и
`ABC-Native-TclTk-win-x64.zip`. Распакуйте каждый в отдельную папку и запустите
`Launch.cmd`. Нажмите F9, введите число в строке под консолью и нажмите Enter.
F8 запускает проверку без выполнения.

Воспроизведение сборки описано в `native/README.md`; для обеих оболочек есть
`native/scripts/build-windows-comparison.ps1`. Полная совместимость с PascalABC.NET
и публичный выпуск с проверкой всех целевых систем остаются следующими этапами.
